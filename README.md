# Testing AI Chapter Skills

Public companion skills for Jason Arbon's book **Testing AI: Engineering Confidence in Non-Deterministic Systems**.

Each chapter skill turns a chapter into a reusable AI-quality workflow: test planning, eval design, quality review, release evidence, examples, and coaching for that topic.

- Author: https://jarbon.ai/
- Testers.ai: https://testers.ai/
