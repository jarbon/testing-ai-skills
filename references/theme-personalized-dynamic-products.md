# Personalized and Dynamic AI Products

**Book location:** Chapter 17  
**Use when:** personalization, deep personalization, confidence engineer, custom dynamic user interfaces, RAG, personalization economics, sample size, personalization n 1, personalize, user owned memory identity, personalization lock portability, human rater, synthetic user, personas synthetic users  
**Source:** [*Testing AI: Engineering Confidence in Non-Deterministic Systems* by Jason Arbon](https://www.amazon.com/dp/B0H8J9GCK1)

## Actions

- Start by testing the personalization contract.
- Test counterfactual users.
- Measure personalization lift separately from safety.
- Use sampling by user segment.
- Test those surfaces separately.
- Test control appropriateness.
- Test cross-device behavior.
- Test explainability of interface choices.

## Evidence to Produce

Produce a decision-oriented evidence package: system and population, cases and slices, measurements and uncertainty, severe failures, known blind spots, and a ship, canary, hold, rollback, or collect-more-evidence recommendation.
